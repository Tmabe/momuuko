첫 실행 세팅

넘버패드 없는 키보드를 쓰신다면 이 강을 건너뛰면 안 됩니다
오늘 할 것

블렌더를 내 키보드에 맞게 만들고, UE와 단위를 맞춥니다.

1. ★넘버패드 문제 — 87키의 첫 관문

블렌더는 시점 전환을 넘버패드에 몰아놨습니다. Num1 정면, Num3 우측면, Num7 위. 87키(TKL)에는 이게 없습니다.

방법 A — 넘버패드 에뮬레이트

Edit → Preferences → Input → ☑ Emulate Numpad

상단 숫자열 1~9가 넘버패드처럼 작동합니다.

부작용이 있습니다 — 원래 상단 숫자열은 에디트 모드에서 버텍스/엣지/페이스 선택 전환(1/2/3)에 쓰입니다. 에뮬레이트를 켜면 그게 막힙니다. 대신 마우스로 상단 아이콘 3개를 눌러야 합니다.

방법 B — 파이 메뉴 (추천)

백틱 키 ` 을 누르고 있으면 → 시점 파이 메뉴가 뜬다
마우스를 방향으로 튕기고 놓으면 시점 전환

에뮬레이트를 켜지 않고도 시점 전환이 됩니다. 숫자열 1/2/3도 그대로 살아 있습니다.

제 권장 — 방법 B로 시작하세요. 에뮬레이트는 지금은 편해 보이지만, 5강 에디트 모드부터 1/2/3을 하루에 수백 번 누르게 됩니다. 거기서 막히면 다시 끄게 되고, 그때는 이미 넘버패드 습관이 들어 있습니다. 처음부터 백틱에 익숙해지는 편이 이득입니다.

2. 단위 — UE와 맞추기

여기서 안 맞추면 모든 모델이 100배 틀어집니다.

Scene Properties(원뿔+공 아이콘) → Units
  Unit System : Metric
  Unit Scale  : 1.0
  Length      : Meters

즉 블렌더는 미터로 두고, 변환은 익스포트 때 처리합니다. 이유는 8강에서 설명합니다.

🧪 계산기 — 블렌더 ↔ 언리얼 단위
↔
UE는 1 유닛 = 1cm입니다. 블렌더 1m = UE 100uu — 이 100배가 초보자 문제 1위입니다.

🪵 나무 상자

가장 단순한 모델로 10단계를 처음부터 끝까지 한 바퀴
오늘 만들 것

흉가에 굴러다니는 나무 상자 하나. 완성해서 언리얼 안에 세워둡니다.

새로 배울 것 — 딱 하나
프로세스 전체를 한 번 완주하는 감각. 각 단계는 최소한으로만 합니다. 잘 만드는 게 목적이 아닙니다.

0. 기술 브리프

폴리곤 예산  : 500 tri 이하
텍스처       : 1024 × 1024, 1세트
머티리얼 슬롯 : 1개
종류         : 스태틱 메쉬

1. 치수

0.6m × 0.6m × 0.5m. 사람 무릎 높이입니다. 눈대중 금지 — 실제 크기를 정하고 시작합니다.

2~3. 블록아웃과 형태

  1. Shift+A → Mesh → Cube (기본 큐브가 있으면 그대로 사용)
  2. N 으로 사이드바를 열고 Dimensions에 0.6 / 0.6 / 0.5 직접 입력
  3. 모서리를 살짝 깎습니다 — 4강에서 배울 베벨을 미리 맛보기로: 에디트 모드(Tab) → A 전체 선택 → Ctrl+B → 마우스 조금 → 클릭
모서리를 깎는 이유 — 완벽히 각진 모서리는 빛을 하나도 안 받아 현실감이 사라집니다. 아주 살짝(1~2cm)만 깎아도 화면에서 확 달라집니다. 일러스트에서 하이라이트 넣는 것과 같은 원리입니다.

4. 원점 · 피벗 · 이름

상자는 바닥에 놓이는 물건이므로 피벗을 바닥 중앙에 둡니다.

  1. 오브젝트 모드에서 Shift+S → Cursor to World Origin
  2. 상자를 바닥(Z=0) 위로 올림 — N 사이드바에서 Location Z를 0.25(높이 절반)
  3. Object → Set Origin → Origin to 3D Cursor
  4. 아웃라이너에서 이름을 SM_Crate_01 로
네이밍 규칙 — SM_=스태틱 메쉬, SK_=스켈레탈, T_=텍스처, M_=머티리얼, UCX_=콜리전. 지금부터 지키면 100개가 넘어갔을 때 살아남습니다.

5. UV

  1. 에디트 모드 → A 전체 선택 → U → Smart UV Project → OK
  2. 상단 탭 UV Editing 에서 펼쳐진 모양 확인

이 강에서는 Smart UV Project로 충분합니다. 제대로 된 언랩은 5강에서 합니다.

6~7. 텍스처 · 머티리얼

Material Properties → New → Base Color를 갈색으로. 이 강은 단색으로 끝냅니다. 텍스처는 6강부터.

8. 익스포트 ★

오브젝트 모드인가 (에디트 모드에서 내보내면 안 됨)
Ctrl+A → All Transforms 적용했는가
면 방향 확인 — 오버레이 ▾ → Face Orientation, 빨간 면이 없어야 함
내보낼 오브젝트만 선택했는가
File → Export → FBX, Selected Objects ☑
Transform → Scale 1.00, Apply Scalings FBX All
Armature → Add Leaf Bones ☐ 끄기 (캐릭터에서 문제됨)

9. UE 임포트

  1. UE 5.7 콘텐츠 브라우저에 FBX를 드래그
  2. Import 창 → Generate Lightmap UVs 체크 상태 확인
  3. 임포트 후 더블클릭 → 크기 확인

10. 검수 — 오늘의 핵심

막히는 지점 ①: 상자가 100배 크거나 작다
원인은 블렌더 m ↔ UE cm 차이입니다. 위 체크리스트의 Apply Scalings = FBX All과 Scale 1.00이 이걸 처리합니다. 그래도 틀리면 임포트 창의 Import Uniform Scale을 100 또는 0.01로.
막히는 지점 ②: 상자가 옆으로 누워서 들어온다
블렌더는 Z가 위, FBX 기본은 Y가 위입니다. 익스포트 Transform 항목에서 Forward: -Z Forward / Up: Y Up을 확인하세요. (UE용 표준값)
막히는 지점 ③: 면이 안 보이거나 속이 비쳐 보인다
노멀이 뒤집힌 것입니다. 에디트 모드 → A → Shift+N (Recalculate Outside).
이 3개를 지금 겪는 게 목적입니다. 상자에서 겪으면 5분이고, 캐릭터를 다 만든 뒤에 겪으면 하루입니다.

이 값은 나중에 바꾸기 어렵습니다. 형태를 다 만든 뒤 줄이려면 처음부터 다시 만드는 게 빠릅니다. 0단계 기술 브리프에 폴리곤 예산이 있는 이유입니다.

UV — 심(Seam) 넣기

원통을 평면으로 펴려면 어딘가는 잘라야 합니다. 종이컵을 펴려면 옆면을 세로로 한 번 자르는 것과 같습니다.

  1. 에디트 모드 → 엣지 선택 모드(2)
  2. 양동이 뒤쪽 세로 엣지 한 줄 선택 → Ctrl+E → Mark Seam (빨갛게 변함)
  3. 윗면 테두리·아랫면 테두리도 각각 Mark Seam
  4. A 전체 선택 → U → Unwrap
심을 어디에 두는가 — 규칙은 하나입니다. 안 보이는 곳. 양동이면 뒤쪽, 캐릭터면 팔 안쪽·머리카락 속. 이건 일러스트에서 접합선 숨기는 감각과 같아서 2D 작가에게 유리한 부분입니다.
막히는 지점: UV가 엉망으로 겹쳐 나온다
심이 부족한 겁니다. 펼칠 수 없는 형태를 억지로 펴면 찌그러집니다. UV 에디터에서 격자 텍스처(체커)를 씌워 보면 늘어난 부분이 바로 보입니다.
→ Material Preview 모드 + 체커 텍스처로 확인하는 습관을 지금 들이세요.

  3. 빨강 = 1(완전히 따라감), 파랑 = 0

왜 무서운가 — 설계 가능한 요소

기법효과예
불쾌한 골짜기사람과 비슷한데 미묘하게 다름관절이 하나 더 있음

실루엣 판독성어둠 속에서 윤곽만으로 식별공포 게임 필수
은폐된 얼굴표정을 못 읽음 → 의도를 모름가면·머리카락
공포 게임의 실루엣 규칙 — 플레이어는 대부분 손전등 원뿔 안의 일부만 봅니다. 그래서 디테일보다 윤곽이 훨씬 중요합니다. 검은 실루엣으로만 찍어봤을 때 "저게 뭔지 모르겠지만 사람은 아니다"가 나오면 성공입니다.

작업 순서 — 실루엣 우선

  1. 검은 실루엣 썸네일 10~20개를 블렌더 밖(CSP)에서 먼저 그린다 ← 강점 활용
  2. 3개만 고른다
  3. 블록아웃 → 스컬프트 (6강 프로세스 동일)
  4. 리토폴 (7강 프로세스 동일)
프로세스가 반복되는 게 보이시나요. 몬스터라고 새 방법을 배우는 게 아닙니다. 같은 10단계에 다른 형태를 넣을 뿐입니다. 이게 이 책의 목적입니다.

★ 몬스터 ②
미믹 (최종 보스)

지금까지 배운 걸 전부 씁니다
오늘 만들 것

벽장 미믹 — 평소엔 가구, 다가가면 괴물. 「무제」의 최대 차별점입니다.

새로 배울 것 — 딱 하나
하드서피스(가구) + 유기체(괴물)를 한 모델에서 결합하기.

왜 최종 보스인가

필요한 것배운 강
정확한 치수의 가구3강 (상자)
하드서피스 디테일·모디파이어5강 (손전등)

설계 결정 — 만들기 전에 정합니다

중요한 갈림길입니다. 미믹을 어떻게 구현할지에 따라 모델링이 완전히 달라집니다.

A안 · 한 모델 + 뼈대 변형 — 벽장과 괴물이 같은 메쉬. 뼈로 문짝을 벌리고 입을 연다.
→ 전환이 매끄럽고 자연스럽다. 리깅이 어렵다.

B안 · 두 모델 교체 — 평소엔 일반 벽장, 발동 순간 괴물 메쉬로 스왑.
→ 만들기 훨씬 쉽다. 전환 순간 티가 날 수 있어 연출(연기·암전)로 가려야 한다.

초보라면 B안을 권합니다. 대신 두 모델의 치수와 피벗을 정확히 일치시켜야 교체 시 어긋나지 않습니다.

★ 텔(전조) 를 모델에 넣기

기획에서 "모든 미믹은 변이 전 관찰 가능한 전조가 있다"고 정했습니다. 그건 프로그래머 일이 아니라 모델러 일입니다.

  • 문틈이 1~2cm 미세하게 벌어져 있음 (일반 벽장은 완전히 닫힘)
  • 바닥에 닿는 부분이 미묘하게 뒤틀림
  • 나뭇결이 한 곳만 결이 다름 ← 텍스처로 처리
진짜 벽장과 미믹은 반드시 같은 폴더에 나란히 두고 비교하며 만드세요. 차이가 너무 크면 아무도 안 속고, 너무 작으면 불공정합니다. 이 조절이 이 게임의 핵심 재미입니다.

   └ SM_Door_Panel  (Static Mesh)  ← 이걸 회전시킨다
